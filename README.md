# To-Do List Application (Python)

## Project Overview
This is a command-line To-Do List application developed using Python. It allows users to manage their daily tasks easily.

## Features
- Add new tasks
- View all tasks
- Delete tasks
- Handle invalid user inputs
- Store tasks permanently using JSON
- Menu-driven interface

## Technologies Used
- Python 3
- JSON
- OS Module

## Project Structure
```text
Task3_ToDo_List/
│
├── main.py
├── tasks.json
└── README.md
```

## How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

## Application Menu
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
